How to Use Nod-Z

Creation

Space: Create nodes or links

  • Press the space bar or double-click anywhere on the canvas to create a node
  • To create a link, select one or more nodes, then press the space bar

Enter: Create a tunnel between two dimensions on the selected node

Selection

Ctrl + Click + Drag: Select multiple objects

Ctrl + A: Select all visible nodes on the canvas

Deletion

Del / Supr: Delete an object (click on the node/template or hover over the link, then press delete)

Ctrl + Z: Restore deleted objects

Clipboard

Ctrl + C: Copy selection

Ctrl + X: Cut selection

Ctrl + V: Paste

Navigation

Click & Drag / Touchpad 2 Fingers: Move the entire workspace around

Arrow Keys: Move the workspace with fine control

Tab: Zoom in and out, adjusting the zoom relative to your mouse position

Mouse Scroll / Touchpad Pinch Zoom: Zoom in or out for a closer or broader view

Teleportation

Click on link: Follow the link to its destination

Click on multidimensional portal: Jump between dimensions

Click on a corner arrow: Focus on the closest node towards that direction

Search

Ctrl + F: Search for nodes by their content (text, image, video, or file)

Workspace Control

Shift: Access the dimensions control panel (create, edit, or switch dimensions)

Toolbar: Use the toolbar for notifications, multi-users, and workspace export features
